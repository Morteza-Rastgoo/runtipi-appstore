# Voice Studio

Self-hosted AI voice studio (Omnivoice) — a 11Labs alternative

## Overview

Voice Studio (Omnivoice) is an open-source, self-hosted AI voice studio. Generate, clone, and edit speech with open models. A self-hosted alternative to ElevenLabs.

## Notes

- Backed by the Omnivoice engine; large model downloads happen on first use into the data volume.
