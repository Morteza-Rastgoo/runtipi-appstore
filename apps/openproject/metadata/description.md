# Open Project

Self-hosted project & issue tracking — an Asana alternative

## Overview

Open Project is a web-based, open-source project management and collaboration platform. Track projects, issues, time, and costs. A self-hosted alternative to Asana and Jira. The official Docker image bundles its own PostgreSQL database.

## Notes

- The image ships with an embedded PostgreSQL; data is persisted under /var/opt/openproject/data.
