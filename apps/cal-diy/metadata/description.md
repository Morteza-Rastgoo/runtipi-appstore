# Cal.diy

Self-hosted scheduling — a Calendly alternative (Cal.com)

## Overview

Cal.diy runs Cal.com, the open-source scheduling platform, self-hosted. Create booking pages, calendars, and integrations. A self-hosted alternative to Calendly.

## Notes

- Cal.com also supports Redis for caching; it runs without Redis for a single-user self-hosted setup.
