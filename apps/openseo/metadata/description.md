# Open SEO

Self-hosted SEO analytics & rank tracking — a SEMrush alternative

## Overview

Open SEO is an open-source, self-hosted SEO platform for rank tracking, site audits, and analytics. A self-hosted alternative to SEMrush and Ahrefs.

## Notes

- Rank data uses the DataForSEO API (bring your own key). The in-app SAM agent uses OpenRouter.
