# Open Whisper

Self-hosted speech-to-text studio — a Whisperflow alternative

## Overview

Open Whisper (Vocalinux) is a self-hosted speech-to-text studio built on Whisper. Transcribe and edit audio with open models. A self-hosted alternative to Whisperflow.

## Notes

- The image ghcr.io/vocahq/vocalinux is a private GHCR repository; it may require a GHCR token to pull if it is not public.
