# Cap

Self-hosted screen & video recording — a Loom alternative

## Overview

Cap is an open-source, self-hosted screen-recording and video-sharing platform. Record your screen, add captions, and share. A self-hosted alternative to Loom.

## Notes

- Multi-service stack: web app + media server + MySQL + MinIO (object storage). The media server uses the prebuilt ghcr.io/capsoftware/cap-media-server image.
